# 2026-11-20

## 应用内更新：自动下载 + 标题栏快捷视图 + 设置页合并（v2.1.x）

用户要求：检测到新版本自动下载，下载完提示重启；有更新时在「最小化/最大化/关闭」旁
放快捷视图；设置页同步显示；主题挪进设置页；关于内容放设置页最后。

### 改动

**主进程新增 `services/update/updateService.ts`（更新状态的唯一持有者）**
- `UpdateState`：`phase` = idle / checking / up-to-date / available / downloading / ready / error / disabled
  + info / progress / filePath / readyVersion / canInstall。
- 由 `initUpdateService()` 在窗口建好后启动：延迟 4s 第一次查，之后每 6h；
  读到 `checkUpdates=false` 直接 disabled。
- 有新版本 → `pickInstaller()` 优先 `*-setup.exe`（只有它能「重启更新」一键装，
  portable 只能手动替换，`canInstall=false`）→ `findDownloaded()` 看 `userData/downloads/`
  里是否已有同版本 >1MB 的 exe（避免重启后再下一遍 100MB）→ 否则自动 `downloadInstaller`。
- 状态每次变化**整份广播**给所有窗口：`IPC.updateState`。渲染进程完全无状态，
  窗口重载后 `getUpdateState()` 拉一次即可复原。
- 下载完发系统 `Notification`（窗口最小化时唯一能看见的提示）；点击通知唤起窗口。
- `installNow()`：`runInstaller()` 后延迟 600ms `app.quit()` —— 必须退出，
  否则安装器覆盖 exe 会被占用。600ms 是实测安装器自身启动所需。
- 调试钩子 `CFGSTUDIO_FAKE_UPDATE=ready|downloading|available|error`：
  不联网伪造状态，专门用来截图核对芯片/面板版式（仓库没发新版时本地复现不出来）。

**IPC 精简**：删掉 `downloadUpdate(url,name)` / `updateDownloadProgress` / `runUpdateInstaller`，
换成 `checkUpdate→UpdateState` / `getUpdateState` / `updateState`(push) / `downloadUpdate()` /
`cancelUpdateDownload` / `installUpdate`。`openExternal` 现在放行 `file://`（打开安装包所在文件夹）。

**渲染进程**
- `state/slices/update.ts`：镜像 + 动作；`apply()` 检测 `phase` 从非 ready → ready 时
  toast 提示「点标题栏『重启更新』」。
- `components/UpdateChip.tsx`：标题栏胶囊芯片（放在 `.titlebar__actions` 末尾，
  靠父级 `padding-right:140px` 自然落在原生窗口按钮左边）+ 绝对定位快捷面板
  （点外面/Esc 收起）。⚠️ 面板伸出标题栏之外，**必须自己写 `-webkit-app-region: no-drag`**，
  否则整块被当成拖拽区点不动。
- `pages/AppSettingsPage.tsx`（新，PageKey `preferences`）：外观 → 版本更新 → 关于（三张卡片，
  关于放最后）。删除 `AboutPage.tsx`、`UpdateNotice.tsx`；侧边栏底部「关于」改成「设置」+「新」角标。
- 标题栏主题下拉移除（`.theme-select` 样式一并删）。

**顺手修的**：`--bg-sunken` 一直被引用但**从未定义**（渲染成透明），已补深色 `#0b0e12` /
浅色 `#eef2f7`。

## 标题栏更新芯片：进度改成「底色深浅占比」

细进度条（2px）换成芯片自身背景：`.update-chip__fill` 绝对定位在左侧，
`width = percent` 百分比，`z-index:-1`（父级 `isolation:isolate`）压在文字下。
配色深蓝/浅蓝一对：`--chip-track`（未下，浅）/ `--chip-fill`（已下，深），
深色主题下是钢蓝 #2c4a6b 与藏青 #15263a。下载中给芯片加 `--busy`，
文字改用满强度 `--text`（灰字压在深蓝那半边会糊）。
总大小未知时用 `cv-chip-fill` 让填充宽度来回涨落。
